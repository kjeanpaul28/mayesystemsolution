🔍 Icyo USSD Ari Cyo

📞 USSD (Unstructured Supplementary Service Data)

USSD ni serivisi yo kwinjira muri telefone ikoresha code zifite imibare n'impu. Ni serivisi ya real-time itanga serivisi nk'igaragaza airtime, gukora transferi, no kubona amakuru ya konti.

1

Uko USSD Ikora

USSD ikora ku buryo ihamagarira seriveri ya operateri, irabisubiza amakuru mu gihe gito (less than 2 seconds).

2

Ibiranga USSD

  • • Ifite * mu ntangiriro
  • • Ifite # iheruka
  • • Nta interineti ikeneye
  • • Ikora kuri telefone yose

💡 Akaranga k'USSD

Ikoreshwa kuri telefone zose
Nta porogaramu ikeneye
Ikora mu gihe gito
Ifasha mu bikorwa by'ibanze

⚠️ Icyitonderwa

  • • Code za USSD zitandukanye kuri operateri
  • • Menya code za operateri wawe mbere
  • • Code nshya zashyirwa haboneka buri gihe
  • • Icyizere wizera operateri wawe gusa
