📊 Field Test Mode

🔧 Field Test Mode

*3001#12345#* Field Test

Kwinjira muri Field Test Mode - Reba signal strength

iOS 6-16
Ingenzi

Uko Field Test Ikora

  1. Andika *3001#12345#*
  2. Kanda "Call"
  3. Field Test izagaragara
  4. Reba signal strength mu dBm
  5. Subira mu home ukanda home button

📶 Signal Strength mu dBm

  • • -50 to -70 dBm: Signal nziza cyane
  • • -71 to -90 dBm: Signal nziza
  • • -91 to -110 dBm: Signal mbi
  • • -111 and below: Signal mbi cyane

🔄 Field Test ya iOS 11+

*3001#12345#* Field Test

Field Test kuri iOS 11 na hejuru - Hambaye gukora

iOS 11+
Hambaye

Inzira ya iOS 11+

  1. Andika code nka mbere
  2. Hitamo "Serving Cell Info"
  3. Reba "rsrp0" cyangwa "rsrq0"
  4. Ibi bireba 4G/LTE signal
  5. Bisubiza signal quality
