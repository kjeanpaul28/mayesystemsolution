1 Intangiriro: Imirongo ya Smartphone

1.1 Ibisobanuro by'Imirongo ya Smartphone

Imirongo ya Smartphone ni ubushobozi bw'ubwenge buba muri smartphones bugamije koroshya imikorere, kuzigabanyiriza umurimo w'umukoresha, kubungabunga battery, kongera umutekano, no gutanga ibikorwa byihuse mu buryo bwa automated.

1.2 Kuki Zitwa "Smart"?

  • Zikoresha sensors + automation
  • Zifata ibyemezo bikoresheje data
  • Zikorera ibintu byinshi automatically
  • Zivana ku mukoresha ibintu byose bikora manual

2.1 Light Sensor

Guhindura urumuri bitewe n'aho uri

  • Auto-Brightness: Screen ihindura umucyo bitewe n'urumuri
  • Benefit: Kubungabunga battery life
📞

2.2 Proximity Sensor

Kumva uko telefone iri hafi y'umuntu

  • Screen Off During Calls: Irazima screen igihe uri kuramaguye
  • Pocket Mode: Ihagarika kugaragaza UI mu mufuka
🔄

2.3 Accelerometer & Gyroscope

Kumva uko telefone ihindagurika

  • Auto-Rotation: Screen ihinduka landscape/portrait
  • Shake to Flashlight: Guhungabanya bigatuma flash yaka
🔐

2.4 Biometrics

Kumva ifoto ry'umuntu n'ibindi

  • Smart Unlock: Gufungura phone bihuse ukoresheje biometrics
  • App Lock Integration: Kugena apps zikoresha biometric
