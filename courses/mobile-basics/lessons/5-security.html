Umutekano wa Telefone

Kurinda amakuru, ibyifuzo, n'ubuzima bw'umuntu ku mugabane w'itumanaho

40 min 8 Ibibazo Advanced

1 Intangiriro: Umutekano wa Telefone

1.1 Icyo Umutekano wa Telefone Utekereza

Umutekano wa telefone ni uburyo bwo kurinda amakuru, ibyifuzo, n'ubuzima bw'umuntu ku mugabane w'itumanaho. Bikubiyemo:

  • Kurinda amakuru: Photos, messages, bank details
  • Kurinda ubuzima: Location tracking, personal safety
  • Kurinda ifranga: Bank accounts, mobile money
🔐

Umutekano ni ugutanga umwete ku byo ufite

🎯 Intego z'Umutekano:

🛡️
Confidentiality

Amakuru ntabwo agaragazwa abatabikeneye

⚖️
Integrity

Amakuru ntabwo yahindurwa n'abatabikeneye

🔑
Availability

Amakuru aboneka igihe byakenewe

2 Ibibazo by'Umutekano

2.1 Ubwoko bw'Ibibazo

Hari ibibazo byinshi bishobora kugira telephone yawe. Bitegurwa n'abantu badafite icyo bakora (hackers) cyangwa n'ibyaha by'ikoranabuhanga.

⚠️

Menya ibibazo mbere y'uko bigutera

🦠

Malware

Critical

Porogaramu mbi zishobora gucengera mu telefone yawe.

Ingero: Viruses, Trojans, Ransomware
🎣

Phishing

High

Abacuruzi b'ibinyoma bagerageza kugufata amakuru.

Ingero: Fake emails, SMS scams
📱

Data Theft

Medium

Gufata amakuru yawe n'abatabikeneye.

Ingero: Unsecured Wi-Fi, Spyware
👤

Physical Theft

Medium

Gufata telefone yawe n'abanyabujiji.

Ingero: Street theft, Burglary
📡

Network Attacks

High

Guhugura amakuru mu buryo butemewe.

Ingero: Man-in-the-middle, Sniffing
📲

App Vulnerabilities

Low

Apps zidakora neza zishobora kugira ibyaha.

Ingero: Weak apps, No updates

3 Uburyo bwo Kwirinda

3.1 Imirongo yo Kwirinda: Layer by Layer

Umutekano mwiza ukoresha uburyo butandukanye (layers) bwo kwirinda. Niba umwe uracyibuka, undi uzakurinda.

🛡️

Layers of Protection

🔒

Layer 1: Physical

Kurinda telefone nk'igikoresho

  • Screen lock (PIN/Pattern)
  • Biometric lock
  • Find My Device
🌐

Layer 2: Network

Kurinda mu buryo bwo gutumanaho

  • VPN usage
  • Secure Wi-Fi only
  • Bluetooth caution
📲

Layer 3: Application

Kurinda porogaramu n'amakuru

  • App permissions
  • Regular updates
  • Official stores only
💾

Layer 4: Data

Kurinda amakuru n'ibyifuzo

  • Regular backups
  • Encryption
  • Secure deletion

4 Encryption n'Umutekano Ukomeye

4.1 Icyo Encryption Ari Cyo

Encryption ni uburyo bwo guhindura amakuru (data) mu buryo butazasobanukirwa n'uzaba atari we wenyine. Ni nk'uburyo bwo gupakira amakuru mu sanduku ifunguye.

🔐 Uko Encryption Ikora:

  1. 1. Amakuru (data) ahinduwa mu mibare (encryption)
  2. 2. Ukoresha code (key) yo gufungura
  3. 3. Nta muntu ushobora gusoma amakuru nta code
  4. 4. Ukoresha code nanone kugirango usubize amakuru (decryption)

🎯 Inyungu z'Encryption:
