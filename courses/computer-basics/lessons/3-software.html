Software: Porogaramu za Computer

Menya ubwoko bw'Software, uko bikorana na Hardware, n'uko uzikoresha mu buzima bw'umunsi

60 min 30 Ibibazo Intermediate

Icyo Software Ari Cyo

Software ni porogaramu cyangwa amabwiriza computer akoresha kugirango akore imirimo itandukanye.

💡 Akarango k'Ingenzi:

Hardware = Igikoresho (Ushobora kugifata)
Software = Porogaramu (Ntibigaragara)

📝 Icyitegererezo:

Hardware ni umubiri, Software ni ubwonko. Nta computer ishobora gukora nta software!

Software Development Life Cycle - Uko software ikorwa

Ubwoko bw'Software

🖥️ System Software ▼

Software ishinzwe gukoresha computer yose. Ni yo itanga serivisi ku software yose.

  • • Operating Systems: Windows, Linux, macOS
  • • Device Drivers: Ibinyabiziga bya hardware
  • • Utilities: Antivirus, Cleanup tools
📱 Application Software ▼

Software ukoresha gukora imirimo itandukanye. Ni yo ukunda gukoresha buri munsi.

  • • Office Suite: Word, Excel, PowerPoint
  • • Web Browsers: Chrome, Firefox, Safari
  • • Media Players: VLC, Windows Media Player
👨‍💻 Programming Software ▼

Software abahanga bakoresha gukora software nshya. Ni ibikoresho by'abprogrammer.

  • • Code Editors: VS Code, Sublime Text
  • • Compilers: GCC, Java Compiler
  • • Debuggers: GDB, Chrome DevTools
